# DSItemBridge

Специализированный легковесный Paper/Bukkit плагин-мост для сервера DeathSwearRPG (Paper 1.21.1).

## Назначение
Решает критические проблемы интеграции между **MythicMobs / Crucible**, **LootContainers** и **PremiumAdvancements**:
1. **Выдача достижений за крафт предметов (`CraftItemEvent`)**:
   - Автоматически выдаёт целевую ачивку из `PremiumAdvancements` (`/padv give <player> <adv> --silent`) при обычном клике и shift-клике в верстаке и инвентаре.
   - Устраняет проблему с неработающим псевдо-триггером `~onCraft` в конфигурациях предметов MythicMobs.
2. **Разблокировка рецептов крафта при получении ингредиентов**:
   - Перехватывает получение ингредиентов из **LootContainers** (контейнеры с лутом / сундуки / головы), обычных сундуков, поднятие с земли и создание в верстаке.
   - Автоматически открывает привязанные рецепты крафта через `player.discoverRecipe(...)`.
   - Воспроизводит приятный звуковой сигнал (`ENTITY_PLAYER_LEVELUP`) и уведомление в Action Bar (`✦ Открыт новый рецепт крафта!`).
3. **Выдача достижений за получение предметов (`acquire-advancements`)**:
   - Позволяет выдать ачивку за получение предмета любым путём (лут из босса, сундук, поднятие с земли, крафт).

## Сборка
Для компиляции и автоматической установки в папку сервера выполните:
```bash
python build.py
```
Скрипт компилирует исходники на JDK 21 с зависимостями Paper API и MythicMobs, упаковывает в `target/DSItemBridge.jar` и копирует в `../ds_rpg/plugins/DSItemBridge.jar`.

## Команды
- `/dsbridge reload` — перезагрузить `config.yml` плагина без перезагрузки сервера.
- `/dsbridge check` — проверить предмет в руке игрока (выводит MythicMobs ID / Material, связанные рецепты, их статус изученности и настроенные ачивки).
- Право доступа: `dsitembridge.admin` (по умолчанию для OP).
